# Object return service

![Alethia Island object-return service](https://raw.githubusercontent.com/Alethia-Island/assets/master/images/sandbox/object-return.jpg)

Self-service object-return terminals help visitors recover items left in the sandbox. Find them around the sandbox, at the main landing point, and on every sky platform.

The service returns objects from the **main sandbox parcel** only. It does not return objects from privacy areas or no-script areas. For help locating or clearing those items, contact staff or use a [help point](/sandbox/help/help-points).

Please take or delete your objects when finished; see the [sandbox rules](/sandbox/rules).

## Before using the service

Object return is intended to help recover items left in the main sandbox parcel. It is a useful safety net, but the simplest way to avoid losing track of a project is to take items back into inventory when you finish each session.
