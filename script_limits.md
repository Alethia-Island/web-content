Scripts are the small programs inside Second Life objects, attachments, HUDs, vehicles, and gadgets. They make things move, animate, talk, track information, run menus, or react when touched. Useful scripts also use part of the region's shared computer resources.

Alethia Island is a Homestead region, so it has less capacity for busy scripted activity than a full region. To keep building, socialising, and exploring smooth for everyone, Alethia monitors the combined script use of all visitors.

The counter near the main landing point shows the total current impact across the region.

## Current region limits

- **Maximum script memory: 16 MiB** — this is the amount of region memory scripts are using. Large scripted objects and heavily scripted avatars can raise it.
- **Maximum script CPU time: 0.750 ms** — this is the amount of processing time scripts are taking from the region. Fast-running, looping, or numerous scripts can raise it.

You do not need to understand these numbers to use the sandbox. In practice, simply avoid bringing many unnecessary scripted attachments, rezzing large automated systems, or leaving active scripted objects behind.

## How to help keep Alethia smooth

- Remove HUDs, animation systems, meters, followers, scanners, and other attachments you do not need while building.
- Keep large scripted builds and test systems to a minimum, especially when the sandbox is busy.
- Remove or take back objects when you have finished testing them. If you have lost an item or cannot find it, use the self-service [object-return system](/sandbox/objects/return) at the main landing point or on a sky platform.
- If an Alethia Island [manager](/contact) asks you to reduce scripts, please do so before continuing.

If sustained script use exceeds the region limit, Alethia may automatically eject the avatar responsible. This protects the experience for other visitors; it is not a judgment on the object or its owner.

## Practical testing tips

- Scripted attachments count too: HUDs, animation systems, meters, followers, scanners, and similar gadgets all contribute to the region's load.
- Before you build, detach anything you do not need for the task at hand.
- Test one scripted system at a time where possible, rather than leaving several automated systems running together.
- Unless granted permission by an Alethia Island [management member](/contact), do not leave automated objects or processes running unattended.
- If objects rez slowly, menus respond late, movement stutters, or scripts appear delayed, reduce scripts or take back nonessential objects. These can be signs that the region is busy.
- If you think an object or attachment is causing a problem, use a [help point](/sandbox/help/help-points) to ask for assistance.

There is no published per-avatar script quota: the limits apply to the region as a whole. See [general information](/general) and the [sandbox rules](/sandbox/rules) for related guidance.
